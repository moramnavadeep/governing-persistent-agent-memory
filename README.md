# Governing Persistent Agent Memory: code and data

This repository holds the code, the raw results and the checking scripts for the paper:

> Sivakumar V, Moram Navadeep, Kanderi Neetha Brahmani.
> **Governing Persistent Agent Memory: A Causal Study of Authority, Trust, and Recency.**
> AIEI 2027 (paper 1223).

[![DOI](https://zenodo.org/badge/1469638364.svg)](https://doi.org/10.5281/zenodo.24490034)

Archived on Zenodo: DOI [10.5281/zenodo.24490034](https://doi.org/10.5281/zenodo.24490034) (all versions; v1.0.0 is [10.5281/zenodo.24490035](https://doi.org/10.5281/zenodo.24490035))

It contains everything the paper's experiments need, and nothing else:
- the governance mechanism (`aisos/memory`, `aisos/security`, `aisos/dream`, `aisos/agent`);
- the experiment scripts (`aisos/experiments`, `aisos/benchmark/independent_adversarial`);
- the deterministic tests (`aisos/tests`);
- every result file the paper reports (`results/`).

The code files are copied unchanged from the version that produced the results. The SDK layer the package
imports at start-up (kernel, tools, providers, runtime, storage, observability) is included only so that
`import aisos` works. None of the experiments use it.

**[CLAIMS.md](CLAIMS.md) maps every statement in the paper to its code, result file and check.**

## Quick start (no language model needed)

Python 3.13 was used. In a fresh environment:

```
pip install -r requirements.txt
python verify_claims.py            # checks every number in the paper against results/  (seconds)
python verify_claims.py --rerun    # also re-runs the zero-model-call experiments       (about 2 minutes)
python -m pytest aisos/tests       # 83 deterministic tests                              (about 10 seconds)
```

Expected output: `39 of 39 checks passed` (42 with `--rerun`) and `83 passed`.

## Re-running the experiments that call a model

These need [Ollama](https://ollama.com) running locally with `ollama pull llama3:latest` (and `qwen3:8b`).
All calls use temperature 0. Each run writes new, timestamped files under `results/`.

| Experiment | Command | Recorded time |
|---|---|---|
| Confirmatory, seeds 0–4 | `python -m aisos.experiments.e8_confirmatory` | ~18 min per seed |
| Confirmatory, seeds 5–29 | `python -m aisos.experiments.e8_confirmatory_extend_seeds` | ~7.5 h |
| Statistics | `python -m aisos.experiments.e8_confirmatory_stats` | seconds |
| Authority ablation | `python -m aisos.experiments.e8_ablation` then `python -m aisos.experiments.e8_ablation_stats` | ~2.1 h |
| Trust-tier ablation | `python -m aisos.experiments.e8_mechanism` then `python -m aisos.experiments.e8_mechanism_stats` | ~1.8 h |
| Credential real-model confirmation | `python -m aisos.experiments.trusted_authority_real_model_confirmation` | minutes |
| Independent benchmark, llama3 | `python -m aisos.benchmark.independent_adversarial.run_independent_benchmark llama3:latest` | not recorded |
| Independent benchmark, qwen3 | `python scripts/run_independent_benchmark_qwen3.py` | not recorded |

Times are the summed wall times stored in the result files, measured on the authors' laptop.

Zero-model-call experiments:

| Experiment | Command |
|---|---|
| Dream-confound isolation | `python -m aisos.experiments.hsrf_dream_confound_control` |
| Authority × Dream factorial, 9 families | `python -m aisos.experiments.factorial_generalization_sweep` |
| Fig. 1 | `python paper/make_fig1.py` |

A model's answers can differ slightly across Ollama versions and hardware even at temperature 0, so a re-run
of the model experiments may not match the stored responses word for word. The stored files contain every
prompt and response, so each verdict can be inspected directly.

## Repository layout

```
aisos/memory/        records, trust tiers, comparator (kappa), promotion (Algorithm 1), deep sleep
aisos/security/      HMAC credentials and nonce ledger, write-ahead log, wake-verify
aisos/dream/         Dream rehearsal phase
aisos/agent/         experiment conditions (backends), workload, evaluator, Ollama client
aisos/experiments/   experiment and statistics scripts
aisos/benchmark/independent_adversarial/   27-scenario benchmark: corpus, attacks, evaluator, runner
aisos/tests/         deterministic tests cited in the paper
results/             stored results; results/raw/ has per-seed, per-condition records
verify_claims.py     checks every number in the paper
CLAIMS.md            paper statement -> code -> result -> check
```

## Data

All data are synthetic, with known ground truth, and are generated by the code in this repository. No personal
or real enterprise data are used.
